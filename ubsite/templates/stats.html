How this is counted

A visit is one browser on one day. Each address is placed and then discarded; what is kept is the place and a number made from the address with a key that is replaced every day, so the same reader on two days counts as two visits. No cookie is set on readers. {% if counted %}This browser's visits are counted: stop counting them. {% else %}This browser's own visits are not counted: count them.{% endif %}
